# Hotel La Mansión

Base de la aplicación móvil de gestión hotelera para Android e iOS.

## Estado actual

Esta primera base contiene únicamente una estructura visual sencilla:

- dashboard inicial;
- navegación inferior;
- pantalla de habitaciones;
- pantalla de huéspedes;
- pantalla de reservas;
- modelos y carpetas organizados por feature.

La base de datos, los formularios y las operaciones del hotel se agregarán en
iteraciones posteriores.

## Ejecutar

```powershell
flutter pub get
flutter run
```
