# Hotel La Mansión

Hotel La Mansión es una aplicación móvil desarrollada para facilitar la gestión
general de un hotel desde una interfaz sencilla y organizada.

El proyecto permite consultar las habitaciones, revisar su disponibilidad y
estado, visualizar la ocupación y registrar nuevas reservas con los datos
principales del cliente y la habitación.
